Đồng bộ Google Sheet (nhiều người cùng nhập)

Dán URL Web App của Google Apps Script đã deploy (xem hướng dẫn bên dưới) để nhiều Sale / GĐKD cùng nhập liệu và đồng bộ chung.

Chưa đồng bộ lần nào

Xem hướng dẫn & code Apps Script

1. Tạo 1 Google Sheet mới, đặt tên bất kỳ.
2. Vào menu Tiện ích mở rộng → Apps Script.
3. Xoá code mẫu, dán đoạn code bên dưới vào.
4. Bấm Triển khai → Triển khai mới → Loại: Ứng dụng web.
5. Mục "Ai có quyền truy cập": chọn Bất kỳ ai (Anyone).
6. Bấm Triển khai, copy URL dạng .../exec, dán vào ô URL ở trên.

Xuất file APK cài trên Android

Sau khi app này được publish lên một địa chỉ web (HTTPS), bạn có thể tạo file APK thật bằng PWABuilder.com (miễn phí, không cần biết code):
1. Vào pwabuilder.com
2. Dán URL app vào ô tìm kiếm, bấm Start
3. Chọn tab Android → Generate Package
4. Tải file .apk về, gửi qua điện thoại và cài (bật "Cho phép cài từ nguồn không xác định" trong Cài đặt Android).
